# BrijRani CRM - Backend

This repository contains the Node.js / Express backend service for the BrijRani CRM/ERP system.

## Setup & Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables by copying `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
